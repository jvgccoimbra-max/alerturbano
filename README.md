# AlertaUrbano - Sistema Comunitário de Registro e Acompanhamento de Ocorrências Urbanas

## Descrição Inicial do Problema
Cidadãos frequentemente encontram problemas em vias públicas (como buracos, lâmpadas queimadas, acúmulo de lixo ou vazamentos) e enfrentam dificuldades para relatar e acompanhar a solução dessas demandas junto aos órgãos competentes de forma ágil.

## Objetivo Geral
Desenvolver uma aplicação web progressiva (PWA) que permita aos cidadãos registrar ocorrências urbanas utilizando geolocalização e evidências fotográficas diretamente do dispositivo móvel.

## Funcionalidades Previstas
- **Geolocalização Automática:** Captura coordenada de GPS do local do problema.
- **Captura de Imagem:** Registro fotográfico da ocorrência pela câmera do celular ou galeria.
- **Modo Offline/Conectividade:** Detecção de rede para armazenamento temporário de rascunhos.
- **Acompanhamento:** Listagem de chamados abertos e status de atendimento.
